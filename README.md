# rigkit

Public support page and privacy policy for Rigcam (iPhone) and Rigdesk (iPad). Plain static HTML served by GitHub Pages.

`index.html` is the Support URL and `privacy-policy.html` is the Privacy Policy URL on file with Apple: do not move or remove them.

## Status

- 2026-11-13: Rigcam 1.0 and Rigdesk 1.0 (build 16) were submitted to App Review and are waiting for review, with manual release. These two pages are the Support URL and Privacy Policy URL on both version pages. No page content changed with this note.
